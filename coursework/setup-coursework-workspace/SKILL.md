# 搭建课程作业工作区

为当前使用者建立可持续使用的本地工作区。通用资产位于 [assets/workspace/](assets/workspace/)；课程和个人偏好从当前使用者取得。

## 1. 确认位置与已有状态

从用户指定目录开始，先读已有的工作区规则、目录说明及工作流；有已有结构时只补缺项并保留原文件。目标位置不明确且会影响写入时才询问。只交付模板时，在用户指定的导出位置生成，不修改其实际工作区。

完成标准：明确目标目录、已有规则、可复用内容及本次新增范围。

## 2. 收集当前使用者的配置

优先沿用本次对话和已有文件中的已确认信息，只询问尚缺且会改变本次结果的事项：

| 信息 | 用途 |
| --- | --- |
| 学校／课号或课程链接等最小课程线索 | 其余身份信息先主动查找，仅询问仍有歧义的学期或班型 |
| 已有课程入口、大纲与材料（如有） | 复用用户已有资料；缺少时通过课程发现查找，不要求用户手工收集完整清单；登录由用户完成，不收集密码 |
| 希望处理的重复作业、单次任务 | 决定哪些需要持久工作流 |
| 语言、表达水平、格式与交付方式 | 建立使用者自己的输出偏好 |
| 需要本人选择或完成的步骤、agent 分工 | 设置实际确认点与交接 |
| 使用者时区 | 展示时间；仍单独核实课程截止时间的时区 |

允许先建立通用骨架，课程和偏好写“未提供／待确认”。已有明确选择时直接接续。用户提供最小课程线索且希望接入课程时，可在骨架完成后使用 `discover-coursework-course` 主动查找；不把可自行取得的资料变成必填问卷。缺少课表时不编造课程，不复制捐赠工作区的课程或账号；新使用者也无需沿用旧使用者的语言、篇幅、工具、模板或选择习惯。

完成标准：已知信息与待确认信息分开；只将当前使用者实际确认的偏好写成默认。

## 3. 生成工作区

读取并复制 `assets/workspace/` 内的文本资产到目标根目录；遇到同名文件，先比较，合并需要的内容并保留旧版。模板中的待填字段属于运行时信息，保留空白或明确待确认，不写入虚构事实。

- 根 `AGENTS.md` 仅保存通用约束和入口。
- `workflows/COURSEWORK-WORKFLOW.md` 是通用流程与已确认个人作业流程的唯一维护位置。
- `templates/ASSIGNMENT-STATUS.md` 用于每次任务；`templates/MATERIAL-SOURCES.md` 用于课程材料来源。
- 在根 `README.md` 的配置区记录当前使用者已知偏好与待确认项，并创建空的 `inbox/`、`courses/`。
- 创建 `workflows/CHANGELOG.md`，用实际日期记录初始化或本次合并；不复制来源工作区的历史。
- 已知课程可创建 `courses/{course-id}/materials/`、`assignments/`；只有最小课程线索时先用 `discover-coursework-course`（若可用）核实并接入，需要配置选定的个人作业流程时再用 `configure-coursework-course`。若由发现 skill 调用本步骤，只完成骨架并返回，避免重复启动发现。相关 skill 不可用时按生成后的工作流和实际材料继续；未提供课程时到骨架为止。

课程外部材料在写入事实或用于答案前，遵守生成后的“通用材料检查”章节。可独立完成的目录搭建不依赖尚未取得的课程材料。

完成标准：生成的规则、模板和目录互相可达；课程事实仍需后续材料核实；没有把骨架完成表述为课程或作业已经准备完成。

## 4. 检查并交付

检查相对链接、文件是否可读、是否误带姓名、账号、私人路径、旧课程链接、旧作业规则或历史进度。未发布、未读到的材料保持待取得；不把用户偏好说成教师要求。

交付根目录和主要文件的可点击路径，说明已建立的部分、待提供信息、是否存在材料检查暂停，以及下一步。按环境支持的方式说明 skill 使用，不假定特定插件、浏览器、联网权限或文档工具已经安装。

完成标准：对方可以从生成的 `AGENTS.md` 与 `README.md` 接续工作，且无需访问任何捐赠者的文件。
