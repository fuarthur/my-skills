# Organize Files

A Codex skill for organizing local files with clear rules and approval.

- Asks your preferences when no rules exist.
- Shows a plan and waits for approval before moving files.
- Preserves files and sensitive paths, with records and an undo script.

## Install

```sh
git clone https://github.com/fuarthur/my-skills.git
mkdir -p ~/.codex/skills
cp -R my-skills/organize-files ~/.codex/skills/
```

## Use

Ask Codex: `Use $organize-files to organize my Downloads folder.`
